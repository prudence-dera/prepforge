# PrepForge Roadmap

## V1 — Local-first study app
- Flashcards with category filtering
- Know / Need Review tracking
- Editable notes
- Quiz mode
- Progress dashboard
- Browser voice interview practice
- LocalStorage persistence
- Portfolio-ready responsive UI

## V1.1 — Study intelligence
- True spaced-repetition scheduling
- Weak-topic queue
- Daily study target
- Import/export flashcards as JSON/CSV
- More interview tracks and custom categories

## V2 — Secure AI interview coach
- Backend API layer (never expose provider API keys in the browser)
- Realtime spoken interviewer
- Dynamic follow-up questions based on the user's answer
- Transcript analysis for technical completeness and STAR structure
- Answer rubric by interview competency
- Session summary with strengths, gaps, and recommended flashcards

## V2.1 — Cloud sync
- Authentication
- Database-backed cards/notes/progress
- Cross-device sync
- Session history

## V3 — Job-specific preparation
- Paste or upload a job description
- Extract skill categories
- Generate a study plan
- Generate role-specific flashcards and mock interviews
- Readiness score by required competency

## Portfolio story
PrepForge started as a real solution to a real problem: technical interview knowledge was spread across notes, chats, and flashcards, while most study tools did not provide enough spoken interview rehearsal. The product combines structured learning with actual answer practice and a roadmap toward adaptive AI coaching.
