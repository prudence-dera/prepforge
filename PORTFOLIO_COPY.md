# PrepForge Portfolio Copy

## LinkedIn Project Description

**PrepForge — AI-Ready Interview Study & Voice Practice App**

Built a responsive React study platform that combines flashcards, interview notes, active-recall quizzes, progress tracking, and browser-based voice mock interviews. I designed PrepForge to solve a personal interview-preparation challenge: turning scattered technical notes into structured practice while also improving how clearly I explain technical decisions aloud. The first study track focuses on Data Engineering topics including SQL, AWS, ETL/ELT, data quality, pipeline reliability, and system design.

**Tech:** React, Vite, JavaScript, Web Speech API, SpeechSynthesis, LocalStorage, responsive CSS.

**Roadmap:** secure cloud sync, adaptive spaced repetition, realtime AI interviewer, transcript-based feedback, and job-specific study tracks.
